# Resultados do modelo das 4 doenças

| Arquivo | Conteúdo |
|---|---|
| `resultados_teste.json` | métricas gerais do teste |
| `teste_intervalos_confianca.csv` | intervalos de confiança de 95% |
| `teste_por_doenca.csv` | precisão, recall, F1 e AP por doença |
| `teste_severidade_confusao.csv` | matriz de confusão da severidade |
| `teste_recusa.csv` | acerto conforme a fração de folhas aceitas |
| `teste_robustez.csv`, `teste_robustez.png` | desempenho com imagens degradadas |
| `gradcam_exemplos.png`, `erros_gradcam.png` | onde o modelo olhou, nos acertos e nos erros |
| `predicoes_teste.csv`, `erros_teste.csv` | previsão de cada folha e análise dos erros |
| `comparacao_modelos.csv` | todos os modelos comparados |
| `metadados.csv`, `descartadas.csv` | divisão treino/validação/teste e imagens descartadas |
| `historico_treino.csv`, `logs/` | histórico e registros do treino e da avaliação |
